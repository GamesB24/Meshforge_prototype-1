# Code of Conduct

Be respectful. Critique the work, not the person. No harassment, and no posting of anyone's credentials, private scenes or personal data.

This is a small project. Maintainer attention is limited. Assume good faith, and stop when someone asks you to stop.

Reports can go to the repository owner through a private GitHub security advisory or a direct message. Do not include secrets in the report. The owner will respond when they can. There is no separate committee.

Anyone who keeps breaking these rules may be blocked from the repository.
